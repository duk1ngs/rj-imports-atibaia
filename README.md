HTML, CSS e JavaScript estáticos em dist/. Sem instalação ou build de framework. O workflow publica dist/ no GitHub Pages a cada push para main. Paths relativos funcionam no Sites e no Pages.

## Conteúdo

Fotos fornecidas pelo usuário, separadas por empresa e otimizadas em WebP sem aumento artificial de resolução. Preços, disponibilidade, garantia e horários precisam de consulta à equipe. Telefones/endereço são os fornecidos no briefing e nas fotos.

## Verificação

Revisão visual desktop e mobile; imagens e recursos locais; WhatsApp 5511955555149; menu e Escape; galeria quando presente; reduced-motion; conteúdo sem JavaScript. Intros curtas com botão Pular e sem bloquear conteúdo. Não foram fabricadas avaliações, métricas comerciais ou autorizações Apple.

QA e matriz completa permanecem no workspace da coleção; não entram na hospedagem. Publicação Sites usa arquivo estático validado pelo helper do plugin. O empacotador shell do plugin não iniciou por ausência de Bash; fallback portátil preserva o mesmo contrato dist/.openai/hosting.json e usa o validador original.
